inkedIn Post Generator – AI Writer

An AI-powered LinkedIn post generator that helps you write authentic, engaging posts in your personal writing style using Google Gemini and LangChain.

✨ Features :
🧠 Learns your tone from past LinkedIn posts or writing samples
💡 Generates new post ideas based on your topic
🎨 Checks if uploaded media (image/video) is relevant to your post
⚙️ Built with Streamlit and LangChain Google Generative AI

💡 How It Works :
Paste your past LinkedIn post samples.
Enter a topic (e.g., “AI in education”).
Upload an image/video (optional).
Click Generate Post → Gemini analyzes your tone and creates a new, human-like post.
If media is uploaded, it checks whether it’s contextually relevant.

🧰 Tech Stack

Streamlit – for UI
LangChain – for LLM chaining
Gemini (Google Generative AI) – as LLM backend
Python dotenv – for API key management
